# 在本机恢复 P3R 主题

公开源码未附完整个人版的图片、视频、字体、音乐和语音，因此直接构建时使用中性主题。现在可以从已经安装的完整个人版导入媒体，在桌面改造版中恢复场景、立绘、月相时钟与随身听皮肤。

在 `source/` 执行：

```sh
npm run import:personal-media
npm run dist:personal
```

默认读取当前用户下 `Programs/xinhai/resources/app.asar`。也可在导入命令后用 `--` 传入其他完整个人安装版的 `resources/app.asar` 路径。导入器只复制媒体目录中允许的文件类型及人物哈希匹配的资源，不执行安装版的程序代码，不读取其资料目录、数据库、日记或模型配置。

输出目录为 `dist/desktop-personal-current/win-unpacked/`，仓库根目录的 `启动桌面版.cmd` 会优先运行它。若旧改造版仍在运行，先从托盘退出，再启动新版本。

在 **10 自定义 → 应用 P3R 共学外观** 恢复长廊、人物、P3R 月相与随身听。这个按钮只改外观，保留学习记录、声音开关和减少动态偏好。已保存的其他主题不会因导入素材自动重置。背景列表和人物库也可以逐项选择。

## 源码和本地素材

媒体及生成的 `catalog.json`、字体样式保存在 `src/renderer/public/personal-media/`，该目录已加入 Git 忽略，也不进入源码完整性清单。源码提交只保留导入和显示逻辑。缺少此目录的干净 checkout 继续使用三张中性示例，不会显示坏图入口。

本地打包会包含已导入素材，因此 `dist/desktop-personal-current/` 是本机使用的构建结果。本流程不上传素材，也不创建公开 Release。

## 验证

`npm test` 同时检查无素材时的中性回退，以及存在素材时的场景、人物筛选、默认外观和文件路径。`npm run test:desktop-wallpaper` 使用隔离资料验证 P3R 主界面、外观按钮、人物库，以及桌面窗口中背景、人物与月相的真实绘制。

2026-11-03 本机导入：21 个场景、29 张人物原始素材，其中三位角色的 14 个差分出现在人物库；共 168 个本地媒体/样式入口。主界面和桌面壁纸的 P3R 画面已核验。
