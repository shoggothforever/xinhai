# 桌面收藏墙

标题栏「收藏墙」进入管理界面，也可在「自定义」中找到「桌面收藏墙」。动态壁纸和收藏墙分别启停，可以同时使用；关闭学习窗口会在托盘继续运行，托盘退出心海会关闭两者。每次启动应用后，按需启用桌面展示。

点「添加本机图片」，选一次文件即可加入收藏，点击封面会打开原图。需要自定义链接或分区时，可以用「添加内容」或在收藏后编辑。编辑时选取本机封面会填入空白的打开地址，已填写的地址会保留。

打开目标支持 HTTP/HTTPS、`steam://nav/games/details/游戏ID`（打开游戏库）、`steam://rungameid/游戏ID`（启动游戏），以及本机 PNG、JPG、JPEG、WebP、GIF、BMP、AVIF 图片和 PDF、EPUB、MOBI、AZW3、CBZ、CBR、TXT 书籍。可直接粘贴 Windows 绝对路径（包括“复制为路径”得到的引号），也可填写 `file:///` 地址，或用「选择本机文件」选取目标。

保存后，管理列表的「打开」按钮会打开原内容，管理列表封面仍用于编辑；桌面收藏墙与全屏浏览直接点击封面即可打开。管理列表中的「打开」也可访问被桌面分区规则隐藏的收藏。目标文件被移动或删除时，会提示重新选择；保存失败会直接在编辑表单中显示原因。未填写链接时，桌面封面点击会回到编辑界面。

内容只有六个属性：`cover`、`time`、`source`、`url`、`description`、`tags`。ID 与封面比例是内部索引和排版数据，不属于内容属性。桌面只显示封面；元数据在管理界面查看。

「整齐网格」「照片墙」按钮直接显示在主面板，点击即保存并同步到桌面与全屏浏览，无需再点应用。「屏幕、区域与分区规则」中可选显示器、区域百分比、封面大小与网格速度，这些设置调整后点「应用展示设置」。网格整体缓慢向上循环，悬停暂停，滚轮手动浏览；照片墙按封面比例随机摆放，旋转后的范围也不重叠，逐张淡出替换，其他图片保持原位。全屏浏览按 Esc 返回。减少动态、全屏前台应用、锁屏与休眠会暂停桌面动态；减少动态时仍显示静态封面。

“只显示”多个 tag 时命中任意一个即可，留空显示全部。“不显示”命中任意一个就排除，并且优先于“只显示”。没有 tag 的内容只在“只显示”留空时出现。

## 导入导出

JSON 导入会合并内容，有目标链接的按链接去重，不覆盖现有条目；每个内容库最多 5000 条。支持顶层数组或下面的格式。导出会把本机封面嵌入 JSON，可迁移到另一台电脑。远程图片保留 URL，本机书籍链接仍指向原路径。显示设置与 tag 规则在本机单独保存。

```json
{
  "format": "xinhai-coverwall",
  "version": 1,
  "items": [{
    "cover": "https://example.com/cover.png",
    "time": "2026-11-03",
    "source": "我的收藏",
    "url": "https://example.com/",
    "description": "留给自己辨认的描述",
    "tags": ["阅读", "待看"]
  }]
}
```

在「桌面收藏墙」点「从 Steam 导入」，可以搜索游戏库、筛选零游玩时长、勾选要收藏的游戏并填写分区 tag。游戏链接打开 Steam 客户端中的游戏详情，重复导入会跳过已有链接。Steam 请求由主进程发起，从 Windows 环境变量读取 `STEAM_API_KEY` 和 `STEAM_ID`（也支持 `STEAM_ID64`），密钥不会进入界面、收藏库或导出文件。Steam 游戏详情需对该 API 请求可见，修改环境变量后要重启心海。

手动添加和 JSON 导入仍可使用。已有浏览器示意页的数据可用「导出到心海」，再在客户端「导入 JSON」；截图示意内容没有真实 URL，需自行补充。收藏库使用用户资料目录下独立的 `coverwall.db` 和 `coverwall-covers/`，原有学习资料完整备份暂不包含它，请使用收藏墙的 JSON 导出备份。

## 实现与验证

收藏墙使用独立透明 Electron 窗口，通过原生宿主挂在桌面图标视图内。动态壁纸仍在图标后方，收藏墙仅覆盖封面区域。Windows 窗口区域随封面更新，间隙不绘制、不接收鼠标；封面与图标重合时由封面接收点击，可调整区域避开图标。原生桌面嵌入依赖 Explorer 的桌面层布局。

桌面收藏墙的 Chromium 窗口须保持 `focusable: true`：设成不可聚焦会对真实鼠标激活返回 `MA_NOACTIVATEANDEAT`，封面虽可显示但点击被 Windows 丢弃。桌面宿主仍保留子窗口、工具窗口与不自动激活样式。原生输入检查同时验证 `WM_NCHITTEST` 和 `WM_MOUSEACTIVATE`，调用从独立进程异步完成，避免阻塞 Electron UI 线程而得到超时的零值。挂载/恢复时产生的临时零尺寸布局也须忽略，防止网格生成负索引。

收藏窗口仅获得筛选后的封面、内部索引与比例，点击时由主进程重新检查规则并打开原目标。修改内容和选择文件的 IPC 只开放给主窗口。导入本机封面会复制、校验并规范化为 PNG，导入 JSON 不能读取任意本机图片路径。

`npm run test:coverwall` 检查六属性、URL/规则校验、SQLite 持久化、JSON 回环、网格/照片墙、原生窗口挂载与鼠标区域、点击链接、全屏以及与动态壁纸共存。`npm run test:desktop-wallpaper` 验证原有桌面壁纸。`npm run dist:coverwall` 输出独立 x64 可运行目录，根目录启动脚本优先选择它。
